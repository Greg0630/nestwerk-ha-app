# FamilyBoard – Home-Assistant-App-Repository

Familien-App für gemeinsame Einkaufslisten und den Familienkalender.

## Installation

Home Assistant → **Einstellungen → Apps → App-Store → ⋮ → Repositories** →
`https://github.com/Greg0630/nestwerk-ha-app` hinzufügen, dann **FamilyBoard**
installieren.

Dieses Repository enthält nur die App-Beschreibung; das Image kommt von
`ghcr.io/greg0630/nestwerk`.
